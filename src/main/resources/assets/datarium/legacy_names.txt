# Legacy (1.12.2) <-> modern asset and registry names, keyed by the resource pack format that introduced them.
# Texture and model names were matched against the vanilla 1.12.2, 1.13.2, 1.16.4, 1.20.1 and 26.2 assets.
#
# T <legacy texture> <format>:<modern texture>[@<cem model>] ...   under textures/, without .png
#     "@model" - only interchangeable while that CEM model is rendering, "@" - never drawn in place of the legacy file
#     "!" - 1.13+ still ships the legacy file name, but for something else
# L <legacy texture> <cem model> <modern layer> ...                modern layers composited while that CEM model is rendering
# M <legacy item model> <format>:<modern item model> ...           under models/item/, without .json
#     "!" - 1.13+ reuses the legacy file name for something else
# I <modern item id> <legacy item id>[:<metadata>]
# B <modern block id> <legacy block id>[:<property>=<value>...] ...
# E <legacy entity id> <cem model> ...                             .jem names tried in order
# P <model class> <mcp field>|<srg field>[<n>] <cem part> ...      1.12.2 ModelRenderer field behind a CEM part
#     "[n]" - element n of a ModelRenderer[] field, "[]" - every element, as <cem part>1, <cem part>2, ...
#     "*" as the class - any model outside net.minecraft, matched by field name alone
# H <cem part> <host part>                                         part with no 1.12.2 field, drawn together with its host
# A <cem part> <source part> <cem model> ...                       part that follows the animated transform of the source
# R <cem part> <parent part> <cem model> ...                       part rendered inside the frame of the parent
